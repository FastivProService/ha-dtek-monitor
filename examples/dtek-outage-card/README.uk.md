# Компактна картка відключень — приклад

Статус ДТЕК, сьогодні/завтра, вибір черги й шкала доби в одній Lovelace-картці. Дані отримуються через `dtek_monitor/schedule_grid` встановленої інтеграції. Це приклад ручного підключення, не окремий HACS-пакет; автоматичного завантаження разом з інтеграцією немає.

## Встановлення

1. Скопіюйте `dtek-outage-card.js` у `/config/www/dtek-outage-card.js` активної конфігурації HA. Якщо `www` створено вперше, перезапустіть HA.
2. Налаштування → Панелі керування → Ресурси: `/local/dtek-outage-card.js?v=review-2`, тип **Модуль JavaScript**. Видаліть дублікати ресурсу. Оновіть сторінку Ctrl+Shift+R.
3. Додайте ручну картку з `dashboard.yaml`, підставивши фактичні повні ID сутностей свого пристрою. Сенсор `status_entity` — доступність графіка, не стан відключення.
4. Не вкладайте в `horizontal-stack`. У поданні «Розділи» використовуйте всю ширину секції.

Обов'язкові `entity` та `status_entity`. Необов'язкові `title`, `updated_entity` і `group` (початкова черга, наприклад `GPV2.2`). Без `group` вибирається підтверджена група будинку; стороння черга не вгадується. При зміні `entity` або `status_entity` вибір і день скидаються.

Графік і повідомлення оператора не вимірюють фактичне живлення вдома. Відсутні дані та прогноз мають окремі позначення. На переході зимового часу зсув підписується для обох меж інтервалу.

## Демо й тести

`demo/index.html` працює на вигаданих даних без HA. Відкрийте локально поруч із JS-файлом.

Браузерний запуск потребує Node.js 22+ та Playwright 1.62.1 із Chromium:

```sh
node --check examples/dtek-outage-card/dtek-outage-card.js
node examples/dtek-outage-card/tests/browser.cjs
```

Playwright має бути доступний через `node_modules` або `NODE_PATH`. Встановлення та запуск у CI описано в `.github/workflows/dtek-outage-card.yml` в корені підготовленого пакета. Цей workflow додається до наявних перевірок репозиторію.

Перевіряються мобільні розміри, інтервали, відсутність даних, стабільність select/option і фокуса при оновленні HA, зміна адреси, старі успішні та помилкові відповіді після зміни користувача/підключення, скасування продовження refresh та 50 слотів 25.10.2026.
